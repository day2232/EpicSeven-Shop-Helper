# 第七史诗商店助手

Windows 桌面助手，支持 PC STOVE 和 MuMu 模拟器窗口连接。

## 使用

下载全部文件到同一目录，运行 `EpicSeven-Shop.exe`。不要单独移动 EXE。
选择平台并连接游戏，打开秘密商店，设置天空石预算后开始。
程序仅购买圣约书签和神秘奖牌；F8 或停止按钮可请求停止。

截图预览在助手窗口内显示，支持鼠标点击和拖动。目标帧率60 FPS，实际帧率取决于电脑和模拟器。预览帧不保存到硬盘，商店识别会保存诊断截图。
“嵌入游戏窗口”使用截图预览，并将源窗口移出屏幕，不是原生窗口嵌入。退出预览可恢复游戏窗口。

## 环境与当前限制

需要 Windows PowerShell 5.1、.NET Framework、Windows OCR 及中文识别语言支持。
运行时可能请求管理员权限。程序使用窗口截图和鼠标消息，不修改游戏内存。
识别无法确认时会停止。交易结果未核实时，应先核对游戏画面再继续。
MuMu 适配及最近修改尚未经过完整验证，OCR 仍可能误识别或停止。截图模式不保证稳定60 FPS。

## 数据

本地记录、截图和设置保存在 `panel-data`，不包含在此发布包。
清空记录会删除本地轮次数据，包括未核实交易记录，不会撤销游戏内操作。

此发布包未执行自动测试或购买测试。
